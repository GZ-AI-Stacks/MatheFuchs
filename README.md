# Mathe-Fuchs — Kopfrechnen üben für Kinder

Verkaufsseite und Demo-Version der Lern-App **Mathe-Fuchs** von GZ-AI.-Stacks.

🌐 **Live:** https://www.gz-ai-stacks.de/MatheFuchs/

## Was ist das hier?

Eine Kopfrechnen-Lern-App für Grundschulkinder. Einmaleins, Plus/Minus, Mal/Geteilt und ein gemischter Modus, mit Level- und Belohnungssystem — alles in einer Single-File-App, die offline auf Handy, Tablet und PC läuft.

## Inhalt dieses Repos

- `index.html` — Verkaufsseite (Landingpage)
- `demo.html` — kostenlose Demo-Version (alle Funktionen, aber begrenzt auf Level 2, kein dauerhaftes Speichern)
- `impressum.html`, `agb.html`, `widerruf.html`, `datenschutz.html` — Rechtstexte
- `img/hero.png` — Hero-Bild, `img/fuchs-freude-1.mp4` bis `-5.mp4` — Belohnungsvideos (KI-generiert)
- `.nojekyll` — verhindert Jekyll-Verarbeitung durch GitHub-Pages
